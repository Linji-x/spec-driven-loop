# Spec-Driven Loop v1.0.0

首个正式版本：先冻结规格，再并行开发；由主 Agent 以证据独立验收。

First stable release: freeze the specification, coordinate implementation, and let the main agent independently judge the evidence.

## 安装 / Install

在 Codex 中调用 / Invoke in Codex:

```text
$skill-installer Install https://github.com/Linji-x/spec-driven-loop/tree/v1.0.0/spec-driven-loop
```

使用 / Use:

```text
$spec-driven-loop <中大型软件需求 / medium-to-large software request>
```

手动安装 / Manual installation:

```text
$HOME/.agents/skills/spec-driven-loop
```

Plugin 形态为 Preview。支持该命令的 Codex 版本可添加 Marketplace，然后从桌面端 Plugins Directory 安装：

The Plugin package is Preview. Codex versions that support the command can add the Marketplace and then install from the desktop Plugins Directory:

```text
codex plugin marketplace add Linji-x/spec-driven-loop --ref v1.0.0
```

## 主要能力 / Highlights

- `Inspect → Grill → Freeze → Agents → Judge → Loop` 完整交付闭环。
- 五份持久文档：PRD、技术设计、验收合同、Agent 计划和执行循环。
- 冻结共享接口与非重叠文件所有权，降低并行集成风险。
- 主 Agent 检查 diff、运行验证并逐项裁判验收证据。
- 支持从 `LOOP.md` 恢复中断工作；无子 Agent 时可串行执行。
- Chinese-first README with a complete English mirror and anonymized Job Dashboard example.

## 升级 / Upgrade

重新运行安装命令即可固定安装本版本。未来升级时将 URL 中的 tag 改为目标版本；升级前可从 Release 资产核对 `SHA256SUMS.txt`。

Rerun the installer to pin this version. For a future upgrade, change the tag in the URL to the desired version and verify the archive against `SHA256SUMS.txt`.

## Release assets

- `spec-driven-loop-skill-v1.0.0.zip` — standalone authoritative Skill
- `spec-driven-loop-plugin-v1.0.0.zip` — Preview Plugin package
- `SHA256SUMS.txt` — SHA-256 checksums for both archives
